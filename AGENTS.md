# Instrucciones del proyecto

## Al finalizar cada cambio

Incluir siempre al final 3 bloques separados, listos para copiar:

1. **Título del commit**: una sola línea, en español, de 50 caracteres o menos.
2. **Descripción del commit**: una sola línea corta, en español, de 50 caracteres o menos.
3. **Actualización**: instrucción directa y breve indicando:
   - Subir únicamente los archivos modificados a GitHub.
   - Pulsar **Commit changes**.
   - No actualizar ni ejecutar nada en Supabase para cambios de frontend.
   - Hacer `Ctrl+F5` si se modificó JavaScript.
   - Si el cambio requiriera SQL o una migración, indicarlo explícitamente como excepción.

## Publicación

- El proyecto no está en Git local; el usuario sube los archivos manualmente a GitHub.
- No hacer commit ni push salvo que el usuario lo pida explícitamente.
- Recordar al usuario hacer `Ctrl+F5` después de subir cambios de JavaScript para evitar caché.
